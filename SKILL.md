# Mimera: Reference-Driven Visual Cloning & Luxury Storefront Engine

Mimera studies reference web applications, extracts design DNA, layout geometries, responsive behavior, and visual tokens, then reconstructs them inside your codebase component-by-component under strict quality rules and user approvals.

## Quick CLI Reference

```bash
# Initialize workspace
bun mimera init --reference <url>

# Capture responsive evidence pack
bun mimera capture

# Extract Design DNA & tokens
bun mimera analyze

# Generate Component Specification
bun mimera specify

# Verify visual parity (+90.0% threshold)
bun mimera simulate --reference <url> --target <target-url> --threshold 90

# Cryptographically seal component
bun mimera lock --component <component-id> -f src/components/<Component>.tsx

# Generate luxury SkyTheme storefront
bun mimera storefront --generate --name "AURA LUXE" --out ./storefront-dist

# Reverse-engineer bundles with REA evidence digest
bun mimera rea <target> --feature <name> --location <loc>
```

## Agent Skills Navigation

- `rea-design-reconstruction`: Orchestrates the tri-engine workflow (REA + SkyTheme + Mimera).
- `using-reference-engine`: Master orchestrator skill enforcing the 5-step loop, zero-guessing, and +90% visual parity gate.
- `skytheme-storefront`: Independent luxury storefront engineering.
- `verify-skytheme`: Invariant verification and drive testing for luxury storefronts and Web Components.
- `visual-verification`: Playwright computer-vision audit, dual-viewport capture, structural edge MSE, and diff scoring.
