# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Mimera treats reference isolation, untrusted DOM sandboxing, and write scope boundaries as critical security invariants.

If you discover a security vulnerability in Mimera:

1. **Do not create a public GitHub issue.**
2. Send report details directly via GitHub Security Advisories or email the maintainer.
3. Include reproducible steps, affected packages, and proof-of-concept evidence.

We will acknowledge receipt within 48 hours and provide a remediation timeline.
